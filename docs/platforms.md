# Площадки, подключение и бесплатные инструменты

Код студии использует локальные инструменты и официальные API. Бесплатная библиотека не означает бесконечную квоту сервиса, одобренный аккаунт или гарантированный доход. Условия зависят от площадки, страны, канала и прав на контент.

## Источники тем

| Источник | Настройка | Значение сигнала |
|---|---|---|
| [Google Trends RSS](https://trends.google.com/trending/rss?geo=US) | Без ключа; регион из двух латинских букв | Популярный поисковый запрос; приблизительный порог объёма, например `1000+` |
| [YouTube videos.list](https://developers.google.com/youtube/v3/docs/videos/list) | `YOUTUBE_API_KEY`, YouTube Data API включён в вашем Cloud-проекте | `chart=mostPopular` по региону; `viewCount` — накопленные просмотры |

Источники обновляются по вашему запросу, не по скрытому расписанию. Получаются метаданные; чужие ролики и изображения не скачиваются. RSS может быть временно недоступен или не возвращать данные для конкретного региона. Балл — локальная эвристика сортировки, а не показатель будущего успеха.

## YouTube

Загрузка реализована через [официальный протокол resumable upload](https://developers.google.com/youtube/v3/guides/using_resumable_upload_protocol) и [videos.insert](https://developers.google.com/youtube/v3/docs/videos/insert). По умолчанию выбран `private`; запрос может задавать `unlisted` или `public`. В результате сохраняется фактическая видимость из ответа API, которая может отличаться от запроса. Приём файла не означает завершение обработки видео.

Настройка выполняется вручную:

1. В своём Google Cloud-проекте включите YouTube Data API, настройте экран согласия и OAuth-клиент согласно [руководству OAuth](https://developers.google.com/youtube/v3/guides/authentication).
2. Получите OAuth access token с разрешением `https://www.googleapis.com/auth/youtube.upload` для своего канала. Запишите его в локальную переменную `YOUTUBE_ACCESS_TOKEN`.
3. Перезапустите студию и начните с проверочного запуска. Для реальной загрузки снимите флажок проверки или используйте CLI `--live`.

Присутствие токена означает только наличие настройки. Студия не получает согласие вместо пользователя, не выбирает канал, не выдаёт токены и не обновляет их автоматически. Просроченный токен нужно заменить самостоятельно. [Квоты](https://developers.google.com/youtube/v3/getting-started#quota) и ограничения загрузок проверяйте в своём проекте. Непроверенные API-проекты, созданные после 28 июля 2020 года, могут загружать только приватные видео до прохождения требуемого аудита; приложение не обходит это ограничение.

Флажки `made_for_kids` и `contains_synthetic_media` передаются в соответствующие поля YouTube. Автор выбирает их по содержанию своего ролика. Профиль `shorts` задаёт геометрию; классификацию ролика на стороне YouTube определяет сама площадка.

`scheduled_at` — время запуска **локальной очереди студии**. Сервер должен работать в этот момент. Поле YouTube `publishAt` эта версия не использует; приватная загрузка не станет публичной сама по себе по указанной дате.

### YouTube Analytics

После успешной загрузки с подтверждённым ID ролика доступен импорт [reports.query](https://developers.google.com/youtube/analytics/reference/reports/query) для собственного канала: дневные просмотры и, по выбору, `estimatedRevenue`. Импорт охватывает все уникальные подтверждённые YouTube ID проекта, включая опубликованные прошлые ревизии, и суммирует их по дням перед сохранением.

- `YOUTUBE_ANALYTICS_ACCESS_TOKEN` используется первым; при его отсутствии берётся `YOUTUBE_ACCESS_TOKEN`.
- Для просмотров нужен scope `https://www.googleapis.com/auth/yt-analytics.readonly`.
- Для денежных отчётов нужен `https://www.googleapis.com/auth/yt-analytics-monetary.readonly`.

Токен только для загрузки не даёт доступ к аналитике. Данные могут появляться с задержкой. Оценка дохода API записывается в `api_estimated_revenue_minor`; подтверждённые выплаты вводятся отдельно в `actual_revenue_minor`.

## Telegram

Используется [Bot API sendVideo](https://core.telegram.org/bots/api#sendvideo), без пользовательской сессии:

1. Создайте собственного бота через BotFather и задайте `TELEGRAM_BOT_TOKEN`.
2. Добавьте бота в целевой канал/чат и выдайте необходимые права отправки. Задайте точный `TELEGRAM_CHAT_ID` — ID чата либо `@имя_канала`.
3. Проверьте адресата, создайте проверочный пакет и затем включите реальную отправку.

Адаптер ограничивает MP4 размером 50 000 000 байт для облачного Bot API. `privacy` относится к YouTube; Telegram отправляет в настроенный чат. Квитанция Telegram содержит фактический `chat_id` и `message_id`. Публикация ботом не подключает монетизацию канала.

## TikTok, Instagram Reels, VK и другие сети

В этой версии — экспорт MP4 и материалов публикации, затем ручная загрузка. Официальные адаптеры, получение доступов и импорт аналитики этих сетей не реализованы. Геометрия 9:16 подходит для многих коротких форматов, но допустимую длительность, музыку, размер файла и правила конкретного аккаунта проверяет автор.

## Озвучка и локальная модель

| Инструмент | Использование | Условия |
|---|---|---|
| [FFmpeg](https://ffmpeg.org/legal.html) | Рендер и кодирование; GPU не нужен | Отдельная программа; лицензия зависит от сборки и включённых компонентов |
| [eSpeak NG](https://github.com/espeak-ng/espeak-ng) | Простая локальная озвучка RU/EN | Открытый движок; голос механический |
| [Piper](https://github.com/OHF-Voice/piper1-gpl) | Локальный нейросетевой голос | Движок и ONNX-модель устанавливаются отдельно; проверьте [model card выбранного голоса](https://github.com/OHF-Voice/piper1-gpl/blob/main/docs/VOICES.md) |
| [Ollama](https://docs.ollama.com/api/generate) | Черновик сценария через локальный `/api/generate` | Локальный loopback-адрес; модель загружается отдельно и имеет собственную лицензию |

Студия не включает модели, музыку или сторонние клипы. Используйте собственные либо разрешённые к использованию материалы. Автоматически полученный текст требует авторской проверки.

## Монетизация и повторная отправка

Прогноз RPM — расчёт на основе введённых допущений, а не обещание дохода. Подключение партнёрской программы, доступность выплат и [правила монетизации YouTube](https://support.google.com/youtube/answer/1311392) проверяются для конкретного канала. Массовое создание сходных роликов само по себе не подтверждает соответствие этим правилам.

При `unknown` проверьте фактический аккаунт: запрос мог завершиться на стороне площадки после потери ответа. Такое задание блокирует повторную отправку того же запроса. После известной ошибки или отмены новый явный запрос может создать новое исполнение. Адаптеры не повторяют внешнюю загрузку автоматически. Секреты храните в локальном `.env` или переменных окружения; файл `.env` исключён из Git. В репозитории публикуется только `.env.example` без реальных значений.
