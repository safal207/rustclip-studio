# Проверка демонстрации Denis

В [examples/demo](../../examples/demo/) находятся готовый вертикальный MP4, отдельная звуковая дорожка MP3 и кадр из видео на второй секунде. Модель Piper, Python-пакеты, пользовательская база и рабочая папка данных сюда не входят.

| Файл | Размер | Длительность | Содержимое |
|---|---:|---:|---|
| [rustclip-studio-demo-denis.mp4](../../examples/demo/rustclip-studio-demo-denis.mp4) | 712 272 байта | 28,021333 с | 1080×1920, H.264; AAC, 48 кГц, стерео |
| [rustclip-studio-voice-denis.mp3](../../examples/demo/rustclip-studio-voice-denis.mp3) | 450 964 байта | 28,152 с | MP3, 48 кГц, стерео |

[denis-demo.json](denis-demo.json) фиксирует SHA256, результаты проверки копирования, `ffprobe` и полного декодирования обоих файлов через FFmpeg. Контейнеры указывают немного разные длительности; точные значения приведены в таблице. Хеш MP4 сверяется с [сохранённым протоколом рендера](denis-render.json). Хеш MP3 записан при подготовке примера: исходный протокол отдельного хеша MP3 не содержит.

[denis-render.json](denis-render.json) — прежний протокол Linux CPU / Piper 1.8.0 / FFmpeg 6.1.1, относящийся к указанным в нём ревизиям кода. Он сохраняет сведения о проверенных 66 тестах и двух реальных FFmpeg-тестах. Эти проверки не запускались повторно ради добавления демонстрационных файлов; новые проверки здесь относятся именно к файлам MP4/MP3 и их упаковке.

[denis-causal-graph.json](denis-causal-graph.json) содержит восемь событий демонстрационного проекта: сценарий, первый рендер с eSpeak, исправление выбора голоса на Piper и новый артефакт. Его `head_hash` и итоговая ревизия совпадают с протоколом Denis. Старый артефакт сохраняется в истории; исправление не стирает предыдущий результат. Граф иллюстрирует локальную цепочку зависимостей, а не внешнее подписанное доказательство.

Пример не публиковался в социальные аккаунты. Показатели просмотров и дохода для него не измерялись. Финансовые данные из прежних тестовых фикстур сюда не включены. Настройка голоса и отдельные лицензии описаны в [docs/voice.md](../voice.md).
